# FME-Quiz

Quiz-Plattform für **Fundamentals of Machine Elements** (Lehrstuhl FMT, Fakultät für Maschinenbau, OVGU Magdeburg).

- Anonymes Login mit Nickname und Passwort, Top 5 auf der Startseite
- **Speed-Modus** (60 s, Serien-Booster ×2/×3) und **Learn-Modus** (Karteikasten-Wiederholung)
- Deutsch, English sowie kombiniert mit Fachbegriffen in Klammern
- Fehler-Meldefunktion an jeder Frage und Admin-Bereich zur Pflege
- Für das Handy optimiert; kostenloser Betrieb mit Supabase und GitHub Pages
